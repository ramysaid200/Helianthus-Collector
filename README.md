# Helianthus Collector

Welcome to the Helianthus Collector repository! 

## Overview
This project contains the files, presentations, and Arduino code (`stepper.ino`) related to the Helianthus Collector project.

## Repository Contents
- **Documentation & Presentations:** Contains PDF and PPTX files with detailed information about the project.
- **Project Data:** Includes the core code (e.g., stepper motor control using Arduino).

## Getting Started
To view the stepper motor code, navigate to `project data/stepper motor code/stepper.ino` and open it with the Arduino IDE.
